# 클로드코드 실행 가이드 — 「쿵쿵이와 친구들」 1화 AI 영상 제작

> 이 문서는 claude.ai에서 진행한 기획 작업을 클로드코드(Claude Code)로 넘겨 실제 이미지·영상 생성을 실행하기 위한 인수인계 문서입니다. 클로드코드는 실제 bash/네트워크 접근 권한이 있어 Hugging Face Space API를 직접 호출할 수 있습니다.

---

## 0. 프로젝트 배경
'쿵쿵이와 친구들' 시리즈 1화 「안녕, 나는 쿵쿵이야!」를 AI 생성 이미지+영상 클립으로 프로토타입 제작하는 것이 목표. 대본, 캐릭터 설정, 씬별 프롬프트, 테마곡 가사는 이미 확정됨 (아래 첨부).

## 1. 환경 준비

```bash
pip install gradio_client huggingface_hub --break-system-packages
```

Hugging Face 로그인이 필요할 수 있음 (특히 ZeroGPU 기반 Space는 쿼터가 계정 단위이므로 로그인 권장):

```bash
huggingface-cli login
# 또는 환경변수: export HF_TOKEN=hf_xxxxxxxx
```

## 2. 사용할 Space 및 확인 필요 사항

| 용도 | Space ID | 비고 |
|---|---|---|
| 이미지 생성 (빠름) | `mcp-tools/Qwen-Image-Fast` | 프롬프트→이미지, 16:9 지원 |
| 이미지 생성 (고품질) | `mcp-tools/Qwen-Image` | 텍스트 배치 강점 |
| 이미지 생성 (대안) | `evalstate/flux1_schnell` | 빠른 테스트용 |
| 이미지 편집(캐릭터 일관성용) | `prithivMLmods/Qwen-Image-Edit-2509-LoRAs-Fast` | 레퍼런스 이미지 기반 각도 변형 |
| 영상 생성 (이미지→영상) | `zerogpu-aoti/wan2-2-fp8da-aoti-faster` | 시작 이미지 + 프롬프트로 짧은 영상 생성 |
| 영상 생성 (프레임 보간) | `mcp-tools/wan-2-2-first-last-frame` | 시작/끝 프레임 사이 보간 |

**⚠️ 중요**: 각 Space의 정확한 API 파라미터명은 실행 전 반드시 아래로 확인할 것 (Gradio 버전에 따라 인자명이 다를 수 있음):

```python
from gradio_client import Client
client = Client("mcp-tools/Qwen-Image-Fast")
print(client.view_api())
```

## 3. 실행 순서 (권장)

### Step 1 — 캐릭터 레퍼런스 시트 먼저 고정
씬별로 캐릭터를 매번 새로 생성하면 외형이 흔들림. 아래 "캐릭터 고정 묘사"로 각 캐릭터 단독 레퍼런스 이미지 1장씩 먼저 생성 → 저장 → 이후 씬 생성 시 동일 텍스트 묘사를 프롬프트에 반복 포함.

가능하면 `Qwen-Image-Edit` 계열로 레퍼런스 이미지를 기반으로 각도만 바꿔가며 생성하는 것이 일관성 확보에 더 유리함 (`mcp-tools/Qwen-Image-Edit-Angles` 참고).

### Step 2 — 씬별 키프레임 이미지 생성
아래 "씬별 프롬프트" 순서대로 이미지 생성. 결과물은 `outputs/images/S1.png` 형식으로 저장.

```python
result = client.predict(
    prompt="<씬 프롬프트>",
    aspect_ratio="16:9",
    api_name="/predict"  # view_api() 결과로 실제 이름 확인 후 수정
)
```

### Step 3 — 이미지 → 영상 클립 변환
Step 2에서 생성한 이미지를 `zerogpu-aoti/wan2-2-fp8da-aoti-faster`에 시작 이미지로 넣고, 아래 "영상 모션 프롬프트"를 적용.

```python
video_client = Client("zerogpu-aoti/wan2-2-fp8da-aoti-faster")
print(video_client.view_api())  # 파라미터명 확인 필수
result = video_client.predict(
    image="outputs/images/S1.png",
    prompt="<모션 프롬프트>",
    api_name="/predict"
)
```

### Step 4 — 편집
생성된 클립들을 `ffmpeg`로 순서대로 이어붙이고, 이전에 작성한 테마곡(Suno로 별도 생성 필요 — 6번 항목 참고)을 배경음악으로 삽입.

```bash
ffmpeg -f concat -safe 0 -i filelist.txt -c copy episode1_raw.mp4
ffmpeg -i episode1_raw.mp4 -i theme_song.mp3 -c:v copy -c:a aac -shortest episode1_final.mp4
```

## 7. 예상 이슈
- ZeroGPU Space는 무료 계정 기준 대기열/쿼터 제한 있음 — 실패 시 재시도 로직 필요
- Gradio API 파라미터명은 Space 업데이트로 바뀔 수 있으므로 매 호출 전 `view_api()` 확인 필수
- 캐릭터 일관성은 프롬프트만으로 완벽 보장 안 됨 — 여러 번 생성 후 톤이 가장 유사한 것을 수동 선별하는 과정이 실질적으로 필요
- 영상 클립 길이가 짧아(4~5초) 실제 씬 연출과 맞추려면 클립 반복재생/속도조절 편집이 필요할 수 있음
